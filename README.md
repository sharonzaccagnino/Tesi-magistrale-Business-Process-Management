# Tesi-magistrale-Business-Process-Management
Analisi del processo di soccorso pre-ospedaliero del territorio provinciale di Rieti, tramite la combinazione di tecniche di process mining (discovery) e simulation con l'obiettivo di mappare il flusso attuale e testarne limiti e miglioramenti.

La metodologia, le limitazioni e gli esiti e i codici Python sviluppati sono riportati nella tesi. Il dataset è riportato nella cartella, in particolare: il dataset originale, una sua copia in preparazione alla fase di processing per il data quality, il dataset finale utilizzato per l'intero studio e una sua ulteriore copia per il calcolo dei parametri di deviazione standard per l'analisi del as-is process.
